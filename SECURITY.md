# Security Policy

## 📅 Supported Versions

This project is currently in **active development**. Security updates will be addressed on a best-effort basis.

| Version | Supported |
|---------|-----------|
| main    | ✅         |
| older   | ❌         |

---

## 🐞 Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a GitHub issue**.

Instead, contact me directly at:

- 📧 Email: [zivbarr47@gmail.com](mailto:zivbarr47@gmail.com)
- 🐙 GitHub: [@vizarb](https://github.com/vizarb)

Please include:

- A clear description of the vulnerability
- Steps to reproduce (if applicable)
- The impact and severity (if known)

---

## 🔐 Responsible Disclosure

All valid reports will be reviewed and addressed promptly. I appreciate responsible disclosure and will credit contributors where appropriate (optional and anonymous reports welcome).

---

## 🚫 Scope

This project is for **educational and portfolio purposes only**, and is **not intended for production use**. While basic security best practices are followed, the application should not be deployed to handle real user data without further security review and hardening.
